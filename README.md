# FPGAmixer

FPGA-based digital audio processor and matrix mixer built on the Digilent Arty
Z7-20 (Zynq-7000), targeting network audio (AVB), USB, and analog I/O via Pmod
I2S2 converters, controlled from a macOS app over OSC/TCP.

See `docs/FPGA Network Audio Device.md` for the original goals and
`docs/FPGAmixer_Architecture_Roadmap.md` for the phased build plan.

## Repo layout

```
FPGAmixer/
├── docs/                          Design docs, architecture, per-phase notes
├── scripts/
│   └── create_project.tcl         Regenerates the Vivado project from sources
├── src/
│   └── rtl/                       Synthesizable HDL
├── constraints/                   XDC pin / timing constraints
└── vivado_project/                (gitignored) generated by create_project.tcl
```

The Vivado project directory is **not** committed. `scripts/create_project.tcl`
is the source of truth; running it regenerates a working project from the RTL,
XDC, and IP configuration in this repo.

## Getting a project open

Requires Vivado 2026.1 with the Digilent board files installed (`Arty-Z7-20`
must appear in the board picker).

```
git clone https://github.com/dweeeezil/FPGAmixer.git
cd FPGAmixer
vivado -source scripts/create_project.tcl
```

The project opens at `vivado_project/FPGAmixer.xpr`. From there: run synthesis,
implementation, generate bitstream, and program over JTAG.

## Current phase

**Phase 3 complete — static 4-in/4-out PCM matrix across both Pmod I2S2
modules (JA + JB), hardware-verified 2026-08-18.** The Phase 3 noise bug
(I2S TX pin-phase race) is fixed; see `docs/bugfix_2026-08-14_phase3-noise.md`.
Next: Phase 4, PetaLinux bring-up, then OSC control per
`docs/FPGA Mixer OSC Standard.md`.

Command-line simulation (Icarus): `make -f scripts/sim.mk all` — seven
testbenches, all expected to pass.

## Hardware

- Arty Z7-20 (Zynq XC7Z020)
- Digilent Pmod I2S2 (CS5343 ADC + CS4344 DAC), one on JA for Phase 1
- Second Pmod I2S2 on JB, unused until Phase 3
- Later phases: OWC Thunderbolt 10G adapter (Mac AVB), Raspberry Pi 5 with
  Intel I350-T4V2 (network audio endpoint / gPTP terminator)
