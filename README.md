# FPGAmixer

FPGA-based digital audio processor and matrix mixer built on the Digilent
Genesys ZU-3EG (Zynq UltraScale+ MPSoC), targeting network audio (AVB), USB, and
analog I/O via Pmod I2S2 converters, controlled from a macOS app over OSC/TCP.

> **Board migration (Sept 2026):** the project moved from the Arty Z7-20
> (Zynq-7000) to the Genesys ZU-3EG, primarily for usable IEEE-1588/PTP
> hardware timestamping on the UltraScale+ GEM. See the roadmap's migration
> note for details. Arty-era reports, datasheets, and per-phase notes are
> preserved under `docs/archive/`.

See `docs/archive/FPGA Network Audio Device.md` for the original goals and
`docs/FPGAmixer_Architecture_Roadmap.md` for the phased build plan.

## Repo layout

```
FPGAmixer/
├── docs/                          Design docs, architecture roadmap
│   └── archive/                   Arty-era reports, datasheets, per-phase notes
├── scripts/
│   └── create_project.tcl         Regenerates the Vivado project from sources
├── src/
│   └── rtl/                       Synthesizable HDL
├── constraints/                   XDC pin / timing constraints (ZU-3EG)
│   └── archive/                   Superseded Arty Z7 XDCs
└── vivado_project/                (gitignored) generated by create_project.tcl
```

The Vivado project directory is **not** committed. `scripts/create_project.tcl`
is the source of truth; running it regenerates a working project from the RTL,
XDC, and IP configuration in this repo.

## Getting a project open

Requires Vivado 2026.1 with the Digilent board files installed (`Genesys ZU-3EG`
must appear in the board picker; board_part `digilentinc.com:gzu_3eg:part0:1.0`,
device `xczu3eg-sfvc784-1-e`).

```
git clone https://github.com/dweeeezil/FPGAmixer.git
cd FPGAmixer
vivado -source scripts/create_project.tcl
```

The project opens at `vivado_project/FPGAmixer.xpr`. From there: run synthesis,
implementation, generate bitstream, and program over JTAG.

## Current phase

**Phase 3 was hardware-verified on the Arty Z7 (static 4-in/4-out PCM matrix,
2026-08-18); the project is now migrating that same RTL to the Genesys ZU-3EG
(Phase 3.5 — re-bring-up on the new silicon).** The Phase 3 noise bug (I2S TX
pin-phase race) is fixed; see `docs/archive/bugfix_2026-08-14_phase3-noise.md`.
Next: rebuild/re-verify on the ZU-3EG, then Phase 4 (PetaLinux bring-up) and OSC
control per `docs/archive/FPGA Mixer OSC Standard.md`.

Command-line simulation: `make -f scripts/sim.mk all` — seven testbenches, all
expected to pass. (The RTL and testbenches are board-independent.)

## Hardware

- Genesys ZU-3EG (Zynq UltraScale+ MPSoC, `xczu3eg-sfvc784-1-e`)
- 2× Digilent Pmod I2S2 (CS5343 ADC + CS4344 DAC). The ZU-3EG's Pmod JA is the
  analog XADC Pmod (LVCMOS18, RC-filtered), so the modules use the digital Pmods
  **JB** (module #1, `jb_*`) and **JC** (module #2, `jc_*`; unused until Phase 3).
- Gigabit Ethernet (TI DP83867CR PHY → RGMII → PS GEM) with working PS
  1588/PTP timestamping — the reason for the board move
- USB Type-C (USB 3.0/2.0, dual-role) for USB-host audio (and later USB-device)
- Optional: Raspberry Pi 5 with Intel I350-T4V2 as a known-good gPTP peer /
  fallback network endpoint
