## Findings to fix (recommended order)

Evidence saved on the board at `/home/amd-edf/avbfail-*.log` — **from the `p15b` boot; the card was reflashed since, so they may be gone**.
2. **H-F1/H-F5 — counters that hide stalls.** The bridges count every period dropped while the far side doesn't read as a "coarse fix" (USB: 20,002 in 100 s while the Mac doesn't record; AVB: the stall above showed only as this). ## Practical facts (learned the hard way this session)

- **Say where every command runs** (Mac / board / PC), what the test does physically, and use real device names; never assume the user knows a tool's flags. The user was right to call out vague steps (memory `user-runs-own-commands`).
- **The Mac's devices:** the board's USB device is **"Topology Control"** (the user, 2026-10-17: the f_uac2 gadget's default AudioControl interface string, which macOS shows as the name; our gadget script's product string isn't what macOS displays; optional fix: set the gadget's control-interface name, e.g. `if_ctrl_name`, in `fpgamixer-usb-gadget.sh`) (channel k = port USB k) and **"StudioRunner AVB:StudioRunner AVB"** (the Mac names AVB devices entity:stream; channel k = port AVB k).
- **Test tools need validating before their verdicts count.** The first null test compared 32 bits and "failed" on the Mac's float path (PortAudio dither); fixed to 24-bit compare, dither off, low latency; it now self-diagnoses (devices opened, per-channel level/zeros/inverted/16-bit) and `main()` is tested over a fake device. Tools: `tools/loopback_null_test.py` (Mac; `pip3 install sounddevice`; `caffeinate -i` for long runs), `tools/osc_stress.py` (protects the null path and everything on Analog ports by default; restores the mix), `tools/fpgamixer_health.sh` (+ `mixer_hw.py health`; not in `p15a`: there use the one-line snapshot in the status doc §6). Send the user new Mac-side files with SendUserFile.
- **On the board:** `journalctl -u fpgamixer-avb-bridge -b | grep …` doesn't finish (a boot's log is huge); always use `-n`. The board's clock reads 1970 (the Mac's gPTP time base): use `-o short-monotonic`. **Reflashing wipes the board's state and on-board snapshots.** The board is reachable only from the Mac (`ssh amd-edf@amd-edf.local`); the user runs every board and Mac command.
- **Build chain:** `create_project.tcl` + `build.tcl` (Vivado, detached; `^RESULT: XSA`), `sdtgen`, the SDT to the VM, `gen-machine-conf`, bitbake (pattern `~/edf/logs/p15a-build.sh`), `xz` on the VM, `scp` to `build/sd/`. **The VM (`ssh edfvm`) is often off: ask the user to start it** (Hyper-V, elevated). Python: Windows set + the VM (263 tests). **Mutation-test new tests**, baseline first: `scripts\mutate_sv.ps1 <mutants.json> <xsim targets>` and `scripts\mutate_py.ps1 <mutants.json> <test modules>` (JSON list of `{name, file, old, new}`; `old` exactly once; `\n` also matches CRLF files; work copies in `%TEMP%`).
